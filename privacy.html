Privacy Policy (गोपनीयता नीति)

अंतिम अपडेट: 6 नवंबर 2026

1. सार

FastPDFimg.com के tools आपके browser में ही चलते हैं। जो file आप चुनते हैं, वह हमारे server पर upload नहीं होती — न हम उसे देखते हैं, न रखते हैं।

2. हम क्या इकट्ठा करते हैं

  • आपकी files / photos / documents: कुछ नहीं। Processing आपके device की memory में होती है और page बंद करने पर खत्म हो जाती है।
  • Account / नाम / फोन नंबर: कुछ नहीं; इस्तेमाल के लिए login ज़रूरी नहीं है।
  • Browser storage: सिर्फ़ आपकी पसंद (Light/Dark theme) आपके अपने browser में सहेजी जाती है। कोई tracking cookie नहीं है।
  • Analytics / विज्ञापन: अभी इस site पर कोई analytics या विज्ञापन tool नहीं लगा है। भविष्य में लगाया गया तो यह policy पहले अपडेट होगी।

3. Hosting और server logs

यह site GitHub Pages (या हमारे चुने हुए hosting) पर चलती है। Hosting provider सामान्य technical logs (जैसे IP address, browser type) अपनी नीति के अनुसार रख सकता है। इन logs में आपकी files शामिल नहीं होतीं। विवरण के लिए GitHub की privacy statement देखें।

4. Third-party संसाधन

Tools की सभी libraries (PDF, OCR आदि) इसी site से load होती हैं, किसी बाहरी CDN से नहीं। इसलिए tools इस्तेमाल करते समय आपका data किसी तीसरे पक्ष को नहीं जाता।

5. WhatsApp / Share बटन

"WhatsApp पर भेजें" बटन आपके phone की share सुविधा खोलता है; file आपके device से सीधे आपके चुने हुए app को जाती है, हमारे server से होकर नहीं। जहाँ यह संभव नहीं, वहाँ सिर्फ़ एक सामान्य text संदेश के साथ WhatsApp खुलता है।

6. बच्चे

यह site सामान्य उपयोगकर्ताओं के लिए है और हम जानबूझकर किसी की निजी जानकारी इकट्ठा नहीं करते।

7. आपके अधिकार

हम आपका व्यक्तिगत डेटा रखते ही नहीं, इसलिए हटाने/सुधारने जैसा कुछ बचता नहीं। फिर भी भारत के Digital Personal Data Protection Act, 2023 सहित लागू कानूनों के अंतर्गत कोई प्रश्न हो तो नीचे संपर्क करें।
